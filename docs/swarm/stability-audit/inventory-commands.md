## Scenario planning notes

- Command fixtures should use a fresh tmux-backed interactive pi session, because several command paths depend on current pane identity.
- The high-risk command paths are `register`, `stop`, `restart`, `pool rotate`, `mailbox reset`, `goal`, and `protocol migrate`.
- The read-only commands (`list`, `status`, `graph`, `task`, `next`, `validate`, `flow`, `trace`, `capture`, `identity show`, `attach`) can usually be combined into one lane if the session output is stable enough for transcript assertions.
