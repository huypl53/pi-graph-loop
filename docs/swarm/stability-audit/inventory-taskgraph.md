## Scenario planning notes

- The highest-risk paths are assignment/claim fencing, validation, closure, rework reopening, and worker sweep.
- A single mock-LLM lane can usually cover `computeReadyNodes` + `swarm_assign_task` + `swarm_update_task` + closure, but rework and force-reopen deserve separate fixtures.
- If a custom graph includes commit-like root nodes, the fixture must verify that git evidence is actually checked before auto-close.
