## Scenario planning notes

- The high-risk lifecycle surfaces are stop/restart, send_keys, register/adopt, goal controls, and the input interception hook.
- Mock-LLM lanes should prefer a fresh tmux session or dedicated pane so the lifecycle events can be observed without cross-session noise.
- `swarm_prune` and `swarm_stop_agent` need explicit negative checks in the scenario because they are authority-gated and can change the swarm topology.
